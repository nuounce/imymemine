# I.MY.ME.MINE

> 실패할 때마다 과거의 내가 동료가 되는 60초 타임루프 탈출극.
> **Fail now. Escape later.**

눈을 떴을 때 나는 이미 시설 안이었다. 이름도, 어떻게 들어왔는지도 없다.
있는 것은 몸에 박힌 **억제 코어(CORE)** 하나, 복도를 도는 **간수(WARDEN)**,
천장에서 좌우로 훑는 **감시안(EYE)**, 그리고 바깥으로 나가는 **봉인된 문(SEALED)** 뿐이다.

내 능력은 하나다. **나는 잔상을 남긴다.**

한 명만 조작한다. 루프를 확정하면 지금까지의 나는 **잔상(afterimage)** 이 되고,
세계는 틱 0으로 되감긴 뒤 그 잔상이 내 옆에서 같은 행동을 다시 한다.
발판을 밟아 줄 사람이 없으면 — 내가 과거에 가서 밟아 두면 된다.
코어를 되찾으면 봉인이 풀린다. 그때 **바깥으로 나가는 건 잔상이 아니라 지금의 나(I)** 여야 한다.

몸은 넷뿐이다. 그래서 게임 제목이 곧 시스템이다.

| 슬롯 | 뜻 | 상태 |
|---|---|---|
| **I** | 지금 조작 중인 나 | 항상 1명, 불투명, 최상단 |
| **MY** | 첫 번째 확정된 나 | 잔상 |
| **ME** | 두 번째 | 잔상 |
| **MINE** | 세 번째 | 잔상 |

네 번째 몸까지 소진하면 `NO ONE LEFT TO BECOME.` — 스테이지가 초기화되고 `DEBT`가 1 오른다.
**DEBT는 세션 내내 절대 리셋되지 않는다.** 실수를 공짜로 지울 수는 없다.

### 시설의 용어

| 화면 표기 | 뜻 |
|---|---|
| **CORE** | 나를 묶어두던 억제 코어. 금색 마름모. 이걸 빼앗아야 바깥 문이 열린다 |
| **WARDEN** | 간수. 순찰하고, 소리를 쫓고, 붙잡는다. 붙잡히면 그 루프는 거기서 끝난다 |
| **EYE** | 감시안. 천장 카메라. 45틱 연속 포착되면 시설 전체가 나를 향한다 |
| **SEALED / EXIT** | 바깥 문. 코어를 들기 전에는 `SEALED`, 들면 `EXIT` 로 바뀐다 |
| **I / MY / ME / MINE** | 네 개의 몸. `I` 만 조작되고, `I` 만 바깥으로 나갈 수 있다 |

## 실행

```bash
npm i
npm run dev      # Vite 개발 서버 → 안내되는 localhost 주소를 브라우저로 연다
```

프로덕션 번들:

```bash
npm run build    # dist/ 에 정적 파일. base: './' 이라 파일 열기로도 동작한다.
npm run preview
```

런타임 의존성 0개. 게임이 도는 동안 **네트워크 호출이 한 번도 없고**, 외부 이미지·폰트·오디오 파일도 0개다.

## 두 가지 모드

타이틀에서 `←` / `→` (또는 `1` / `2`)로 고르고 `ENTER` 로 시작한다.

| 모드 | 마이크 | 내용 |
|---|---|---|
| **EASY** | 안 씀 | 키보드만으로 플레이한다. 아래 "결정론" 절의 마이크 비트가 항상 0 이라 기존 동작과 완전히 동일하다 |
| **LISTEN** | **씀** | 실제 마이크로 숨소리와 주변 소음을 듣는다. 시끄러우면 그 자리에서 소음이 발생하고 WARDEN 이 조사하러 온다 |

`LISTEN` 을 고르면 시작 직후 **2초간 환경음을 측정한다**(`조용히 해주세요 — 환경음 측정 중`).
모든 임계값은 이 바닥값 **대비 상대치**다 — 해커톤 현장처럼 시끄러운 곳에서도 플레이할 수 있어야 하므로
절대 임계값은 쓰지 않는다. 그래도 안 맞으면 `−` / `=` 로 감도를 7단계로 조절한다(현재 감도는 HUD 에 표시).

인게임 HUD 좌상단에 `LISTEN` 배지와 **4칸 음량 미터**가 뜬다. 첫 칸은 안전 구간(레벨 0)이고,
둘째 칸부터가 소음이 새는 구간이라 그때부터 붉게 맥동한다.

> **`S ▸ STORY`** — 타이틀에서 `S` 를 누르면 인트로 카툰을 다시 본다.

### 과거의 나의 숨소리가 지금의 나를 배신한다

LISTEN 모드의 진짜 규칙은 이것이다. **마이크 소리도 테이프에 녹화된다.**

3루프에서 기침한 순간은 사라지지 않는다. 그 잔상은 매 루프 정확히 같은 틱에 다시 기침하고,
간수는 매번 그쪽으로 온다. 지울 수 있는 방법은 `Q` 로 그 잔상을 덮어쓰는 것(스테이지당 1회)이나
`Backspace` 2초 홀드로 전부 되돌리는 것(`DEBT +1`)뿐이다.
"실패한 나는 동료이자 **지울 수 없는 부채**"라는 이 게임의 컨셉이 소리에서도 그대로 성립한다.

### 개인정보

- **오디오를 저장하지 않는다.** 녹음 버퍼도, 파일도 없다.
- **오디오를 전송하지 않는다.** 이 게임은 런타임에 네트워크 호출을 **한 번도** 하지 않는다(SPEC §0).
- `AnalyserNode` 에서 읽은 음량(RMS)은 그 자리에서 **0~3 정수**가 되고 즉시 버려진다.
  테이프에 남는 것은 **틱당 2비트의 음량 레벨**뿐이며, 그것으로는 어떤 소리였는지 복원할 수 없다.
- 마이크 스트림은 모드를 빠져나갈 때(타이틀 복귀·EASY 전환·실패) `MediaStream.stop()` 으로 반드시
  반납한다 — 마이크 표시등이 켜진 채 남지 않는다.
- 권한 거부·미지원·장치 오류 시에는 **자동으로 EASY 로 폴백**하고 화면에 사유를 한 줄로 알린다.
  게임이 죽거나 멈추는 경로는 없다.

`getUserMedia` 는 보안 컨텍스트를 요구한다. `npm run dev` 의 `localhost` 주소는 보안 컨텍스트라 그대로 동작하고,
`file://` 이나 http LAN 주소로 열면 LISTEN 이 자동으로 EASY 로 떨어진다(사유가 화면에 뜬다).

## 왜 결정론인가 — 아키텍처

잔상은 **저장된 궤적이 아니라 저장된 입력 테이프**다.

```
LOOP N 시작 → 월드를 틱 0으로 리셋
           → 잔상 1..N-1 을 각자의 Uint8Array 테이프로 재생 (동시)
           → 플레이어는 새 몸을 실시간 조작 (동시)
           → 확정 → LOOP N+1
```

궤적을 저장했다면 잔상은 "지나간 영상"에 불과하다. 입력을 저장하고 **매 루프 세계를 처음부터 다시
시뮬레이션**하기 때문에, WARDEN 은 이번 루프에 존재하는 *모든* 몸에 반응하고 그 반응까지 완전히 재현된다.
과거의 내가 간수를 끌고 가면, 그 간수는 진짜로 그쪽에 가 있다.

이게 성립하려면 리플레이 오차가 **근사적으로 0이 아니라 정확히 0**이어야 한다. 그래서:

- **고정 틱 60Hz.** accumulator 방식(`src/engine/loop.ts`), 프레임당 최대 5틱, 잔여분 이월.
  렌더 프레임레이트가 흔들려도 시뮬이 전진하는 횟수는 벽시계 시간에만 의존한다.
- **시뮬 내부에 부동소수점이 없다.** 모든 좌표·속도·타이머가 정수 "서브픽셀"(1px = 256).
  대각선 이동 속도는 `floor(v/√2)`를 상수로 하드코딩했다(`WALK_DIAG = 362`, `RUN_DIAG = 588`).
- **시야 판정에 `sqrt`/`atan2`가 없다.** 반각 50°의 탄젠트를 1000배 정수로 고정해
  `|perp| * 1000 <= 1192 * forward` 로 판정한다. 거리 비교는 제곱거리 정수 비교.
- 입력은 틱당 **1바이트 비트마스크**(`UP=1 DOWN=2 LEFT=4 RIGHT=8 INTERACT=16 RUN=32`), 테이프는 `Uint8Array`.
  **비트 6~7 은 마이크 레벨(0~3)** 이다 — 다음 항목을 보라.
- 시뮬 내부에서 `Math.random()` / `Date.now()` / `performance.now()` / DOM 접근 **전부 금지**.
  엔티티는 id 오름차순 고정 순서로만 갱신하고, 틱 내부 갱신 순서도 고정이다.
- **렌더는 SimState 를 읽기만 한다.** 모션 트레일·게이트 개폐 보간·화면 흔들림·방사 링,
  그리고 아래 "시설 레이어"(비네트·주사선·형광등 깜빡임·바닥 반사)까지 전부
  `src/render/renderer.ts` 의 `ViewState` 에 산다. 형광등 깜빡임 간격은 렌더 전용 LCG로 뽑는데,
  그 난수가 시뮬 상태에 한 번이라도 닿으면 결정론 해시가 프레임레이트에 오염된다.

### 마이크를 넣고도 결정론이 살아 있는 이유

실시간 마이크 입력을 시뮬레이션에 직접 넣으면 매 루프 소리가 달라진다.
그러면 **잔상이 매번 다르게 행동하고 게임이 붕괴한다.** 그래서 그렇게 하지 않았다.

**마이크 소리도 테이프에 녹화한다.**

```
조작 중인 몸(I): 매 틱 마이크 레벨(0~3)을 입력 마스크의 비트 6~7 에 OR → 테이프에 녹화
잔상          : 녹화된 마이크 비트를 그대로 재생 (실시간 마이크는 잔상에 절대 닿지 않는다)
```

- `src/engine/mic.ts` 는 **시뮬 밖**이다. `getUserMedia` → `AudioContext` → `AnalyserNode` 로 RMS 를 읽어
  0~3 정수로 양자화하는 것이 전부다. 어택은 빠르고 릴리즈는 느린 스무딩과 레벨 홀드를 걸어 딸깍거리지 않게 했다.
- `src/sim/` 은 `AudioContext` / `navigator` / DOM 을 **한 번도** 참조하지 않는다.
  시뮬이 보는 것은 정수 비트뿐이라 헤드리스 테스트가 그대로 성립한다.
- 마이크 소음은 기존 달리기 소음과 **같은 경로**를 탄다. 한 몸은 12틱마다 최대 한 개의 소음만 내고,
  뛰면서 동시에 기침해도 이벤트가 둘로 늘지 않고 반경만 큰 쪽을 쓴다.
- 반경은 레벨에 비례한다: 레벨 1 = 96px, 2 = 176px, 3 = 272px (달리기 소음은 160px).
- **EASY 모드에서는 이 비트가 항상 0** 이라 기존 동작과 완전히 동일하고, 기존 테스트가 그대로 통과한다.

결과적으로 재생 오차는 마이크를 켜도 **여전히 정확히 0** 이다. 그리고 그 대가로 이런 규칙이 생긴다 —
**과거의 나의 숨소리가 지금의 나를 배신한다.**

`src/sim/` 은 브라우저 API를 전혀 모른다. 그래서 그대로 헤드리스로 돌릴 수 있다 — 다음 항목이 그 이야기다.

## 테스트

```bash
npm test
```

- **`tests/determinism.test.ts`** — 무작위 입력 테이프 100세트를 각각 2번씩 시뮬레이션하고,
  모든 엔티티의 좌표·상태·타이머를 포함한 최종 상태 해시(FNV-1a)를 비교한다. **불일치 0**이어야 통과.
  이 테스트가 깨지면 잔상 재생이 어긋난다는 뜻이고, 그건 게임의 핵심 메커닉이 무너졌다는 뜻이다.
- **`tests/solvability.test.ts`** — 5개 스테이지 각각에 하드코딩된 정답 입력 테이프를 헤드리스 시뮬에
  먹여 `cleared === true` 이면서 사용 잔상 수가 `par` 이하임을 확인한다.
  손으로 만든 레벨이 실제로 풀리는지, 그리고 메달 기준이 달성 가능한지를 사람이 아니라 기계가 증명한다.
- **`tests/rules.test.ts`** — 조기 확정·시체·DEBT·덮어쓰기 1회 제한 등 SPEC 의 규칙들을
  대조군과 함께 검증한다.
- **`tests/mic.test.ts`** — LISTEN 모드가 결정론을 깨지 않는다는 증명. ① 마이크 비트가 섞인
  테이프도 2회 재생 시 상태 해시가 완전히 동일하고, ② 레벨이 높은 틱에 소음 이벤트가 실제로
  발생하며 레벨 0 이면 발생하지 않고(대조군), ③ 마이크 비트가 이동 비트를 한 서브픽셀도
  오염시키지 않는다. 브라우저 없이 헤드리스로 돈다 — 시뮬이 보는 건 정수 비트뿐이기 때문이다.

> 이 프로젝트는 게임 런타임에 AI/네트워크를 쓰지 않는다. AI 활용의 증거는 런타임이 아니라
> **개발 프로세스** — 위 두 자동 검증(결정론 회귀 + 레벨 solvability 증명) 이다.

타입 검사만 따로:

```bash
npx tsc --noEmit
```

## 심사용 3분 데모 루트

**1분차 — 스테이지 1 `THE CELL` (아하)**

1. 발판 위로 걸어간다. 게이트가 열린다. 발판에서 내려온다. 게이트가 닫힌다. → *"사람이 한 명 더 필요하다."*
2. 발판 위에 선 채로 `R`. 화면이 되감기고 **방금의 내가 발판 위에 서 있다.**
3. 열린 게이트를 통과해 CORE 를 집고 EXIT 로. `MINIMUM AFTERIMAGE ★`.

여기까지 30초 안에 도달하도록 설계했다. 이 게임이 무엇인지는 이 한 번으로 전달된다.

**2~3분차 — 스테이지 5 `THE THRESHOLD` (와우)**

WARDEN 2 · EYE · 레버 · 상자 · 시간차 버튼이 한 화면에 있고, 몸은 4개뿐이다. par 3.

보여줄 것:
- 잔상이 `Shift`로 뛰어 소음을 내고 간수를 반대편으로 끌고 간다 — **과거의 내가 미끼가 된다.**
- 체포당한 잔상은 사라지지 않는다. **시체가 되어 그 자리에서 계속 발판을 누른다.**
  실패한 나도 동료다. 그리고 지울 수 없다.
- 상자를 발판에 올려 몸 하나를 아낀다 — "몸은 유한하다, 세계를 써라."
- 하나의 잔상이 전반에는 레버를, 후반에는 발판을 맡는다. par는 **잔상을 다역으로 쓸 때만** 달성된다.

시간이 남으면 `Q`로 잔상 하나를 덮어쓰는 장면(스테이지당 1회)과,
`Backspace` 2초 홀드로 전부 되돌릴 때 `DEBT`가 오르는 장면을 보여 준다.
게임 오버는 없다. 부채만 쌓인다.

## 파일 구조

```
index.html
src/
  main.ts            부트스트랩 — 캔버스·입력·오디오·페이즈 디스패치
  engine/
    loop.ts          accumulator 고정 틱 루프
    input.ts         키보드 → InputMask + 메타키 엣지 트리거
    audio.ts         WebAudio 절차 생성 SFX (에셋 0)
    mic.ts           LISTEN 모드 마이크 → 0~3 레벨 (시뮬 밖. 저장·전송 없음)
  sim/               DOM 을 전혀 모르는 순수 정수 시뮬레이션
    constants.ts     매직넘버 금지 — 모든 상수가 여기 있다
    types.ts         SimState / Body / Guard / LevelDef / InputMask …
    world.ts         createWorld / stepWorld
    physics.ts       AABB 축분리 충돌, 상자 밀기, 정수 레이캐스트
    guard.ts         WARDEN 상태기계
    devices.ts       채널 평가 — 발판 / 버튼 / 레버 / 게이트 / EYE
    hash.ts          FNV-1a 상태 해시 (결정론 테스트용)
  game/
    session.ts       루프 진행, commit / overwrite / reset, DEBT, 메달
    levels.ts        5개 스테이지 (순수 데이터)
  render/
    palette.ts       아트 디렉션 팔레트 + 시설 분위기 상수
    renderer.ts      월드 드로우 + ViewState (렌더 전용 효과 · 시설 레이어)
    hud.ts           HUD · 타이틀 · 전환 · 클리어 오버레이
tests/
  determinism.test.ts
  mic.test.ts
  rules.test.ts
  solvability.test.ts
```
