## §R 파이프라인 레퍼런스 (새 세션 필독 — 이것만 알면 전부 재현 가능)

1. **게임 자동 플레이**: `npm run dev`(localhost:5173, dev 전용) → 페이지의
   `window.__imm` 후크 사용 — `stage(n)` 스테이지 점프, `queue(masks)` 틱 단위 입력
   주입(틱당 마스크 배열), `pending()`, `press('COMMIT')` 루프 확정,
   `introShow(t)/introPlay()`, `interludeShow(id,t)/interludePlay()`.
   마스크 상수: U=1 D=2 L=4 R=8 E(상호작용)=16 RUN=32 FLASH=256, 한 타일=16틱, 60틱=1초.
   **루프 테이프 사이에는 press('COMMIT') → 0.7초 대기.** 큐는 루프 리셋 직후(300ms 내)
   주입해야 잔상 타이밍이 맞는다.
2. **주의 3가지**: ① 게임은 탭이 화면에 보일 때만 진행(rAF) — 창을 앞에 세울 것
   (창 식별은 `document.title='REC-TARGET'` 후 AppleScript AXRaise). ② 인트로는
   컷마다 키 입력 대기 — 컷당 2.6초 간격 keydown 자동 발사. ③ 도구 호출 왕복 지연이
   수 초라 **녹화를 먼저 걸고 나서 실행을 예약**할 것.
3. **테이프 출처**: `tests/solvability.test.ts`의 스테이지별 Solution 리터럴을
   `edit-scripts/extract-tapes.ts` 방식(esbuild 번들→node 실행)으로 JSON화.
   기존 S1·S5는 `edit-scripts/tapes.json`.
