## 1. 환경 단서 4개 추가 — `src/render/note.ts` `NOTES_BY_STAGE`

기존 항목(예: `01_I` (1,3) PRINT)과 같은 구조로 4개 추가. 좌표는 아래 배치 원칙으로
개발자가 정한다: **필수 동선 밖 + 통행로에서 1~2타일 인접 + 기존 단서와 다른 방(같은
스테이지에 2개일 때)**. 스테이지당 단서는 최대 1개 유지 — 아래는 전부 단서가 없던
스테이지다.

| 스테이지 | kind | text (자구 확정) |
|---|---|---|
| `03_I` | `PRINT` | `적재 지침 — 자세 교정은 경화 전에 완료할 것.` |
| `07_MY` | `PRINT` | `관측 지침 — 추적하지 말 것. 기록만 할 것. 개체가 지치는 지점을 표시할 것.` |
| `11_ME` | `SCRAWL` | `넷이면 된다고 했다. 넷째가 나였다` |
| `14_MINE` | `PRINT` | `회수 기록 — 일부 개체에서 발화 잔류. 청취하지 말 것.` |

- 07_MY를 고른 이유: WATCHER가 처음 의미를 갖는 2막 후반이며 06은 HOUND 중심이라 07이 맞다.
- 11_ME의 SCRAWL은 마침표 없음 — 기존 손글씨 2개(`여기까지 온 건 나만이 아니다`,
  `문은 열려 있었다...`)와 같은 관행. 손글씨는 이 추가로 전체 3개가 되고 **이게 상한**이다.
- 패널 자동 조판이 ` — `와 ` / `로 자르는 점 확인(07 문안은 ` — ` 1회 + 마침표 구분).

**테스트**: `tests/notes.test.ts`가 단서 원문을 고정하고 있다 — 신규 4개도 같은 패턴으로
원문 고정 테스트를 추가할 것. 시뮬 무영향(해시 불변) 보증이 기존 테스트에 있다면 4개
추가 후에도 통과해야 한다.

## 2. 막간 2 「선반」 컷1 — 빈 칸 + `출고` 태그 — `src/render/interlude.ts`

막간 2 컷1(선반 방 와이드, 조사 시점 L955~1031)에서:
- 선반 칸 중 **하나를 비운다**(실루엣 미배치). 위치는 화면 중단 — 시선이 자연히 닿되
  구도 중심은 아닌 칸.
- 빈 칸 안쪽에 인쇄체 태그 1개: `출고` — 막간 3 일련번호에 쓴 `printedLine`(조사 시점
  L755~786, 지터 0·고정 자간)을 재사용한다. 크기는 일련번호와 동급(작게). 흰 강조 금지 —
  종이 태그 느낌으로 어둡게.
- **컷1의 무자막은 유지한다.** 캡션·내레이션 추가 금지.

## 3. YIELD 엔딩 인쇄체 1줄 추가 — `src/render/hud.ts` 엔딩 화면

YIELD(DEBT 3+) 엔딩에서 `수율 양호.`(조사 시점 L2919, 지연 후 표시) **뒤에 추가 지연을
두고** 한 줄 더:

`전 배치 잔여물 — 수거 완료.`

- 표시 순서: 벽의 금 + 새 금 → (지연) `수율 양호.` → (추가 지연, 기존 지연과 동일 간격)
  이 줄. 같은 `printLine`, `wobble 0`(반듯한 인쇄체).
- TOGETHER·LEFT_BEHIND 분기에는 넣지 않는다.

## 4. 속말 변주 1건 — `src/game/whisper.ts` `ACT_LINES` captured 3막 항목

⚠ 초안(2막)에서 **3막으로 정정된 항목** — 근거는 문서 상단 참조.

- 현행 (3막, 조사 시점 배열 인덱스 2): `됐어. 쟤도... 나였는데.`
- 교체: `됐어. 쟤도... 나였는데. 선반보다는, 여기가 나아.`
- 2막 항목(`됐어. 쟤도 쓸 데가 있어.`)은 **그대로 둔다.**
- 호칭 사다리 유지 확인: 3막 = 망설임(`쟤도... 나였지` 계열) — 교체문도 같은 층위다.

**테스트**: `tests/whisper.test.ts`의 대사 중복 금지·15스테이지 완비 검사가 통과해야
한다. 속말 무영향(해시 동일) 검사 포함 전체 `npm test` 통과가 완료 조건.
