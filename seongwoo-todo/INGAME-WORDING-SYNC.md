## 2. `src/render/intro.ts` — 컷 7 풍선 2분할 (구현 포함)

현행(1443행 부근): 캡션 하나가 `...그럼 내가 남으면 되지. 넷이나 있잖아, 내가.`
목표: 풍선 2개 — 결심(`그럼 내가 남으면 되지.`) 뒤에 농담(`나, 넷이나 있잖아.`)이
**작게, 반 박(26틱) 늦게** 나타난다 (COMIC-SCRIPT 컷 7).

빌드 검증된 구현:

1. `captionBox` 함수(309행 부근)의 시그니처 끝에 크기 인자를 추가하고, 함수 안의
   `let size = 14;`를 `let size = baseSize;`로 바꾼다:

   ```ts
   function captionBox(
     g: CanvasRenderingContext2D,
     r: Rect,
     text: string,
     corner: 'tl' | 'tr' | 'bl' | 'br',
     t: number,
     seed: number,
     baseSize = 14,   // ← 추가. 기존 호출부는 손대지 않아도 된다.
   ): void {
   ```

2. `panel7`의 기존 captionBox 호출(1443~1450행)을 아래 두 호출로 교체한다:

   ```ts
   // 결심과 농담 사이의 한 박 — 두 번째 풍선은 작게, 반 박(26틱) 늦게 (COMIC-SCRIPT 컷 7).
   captionBox(
     g,
     { x: 40, y: 34, w: CANVAS_W - 80, h: 90 },
     '그럼 내가 남으면 되지.',
     'tl',
     t,
     91,
   );
   captionBox(
     g,
     { x: 96, y: 78, w: CANVAS_W - 136, h: 60 },
     '나, 넷이나 있잖아.',
     'tl',
     t - 26,   // 페이드 시작이 26틱 늦어진다 (captionBox 내부가 t-14 기준이므로)
     92,       // seed를 다르게 — 첫 풍선과 기울기가 겹쳐 보이지 않게
     11,       // 더 작은 글자
   );
   ```

   컷 로컬 틱은 `CUT_TICKS = 132`이므로 26틱 지연이면 두 번째 풍선이 40틱쯤에
   떠서 컷이 끝나기 전 충분히 읽힌다.

## 4.5 `src/game/whisper.ts` — 호칭 사다리·키 이름 (제안, 팀 확인 후)

| 줄 | 막 | 문제 |
|---|---|---|
| 175, 191 | 1막 | `다른 내가`/`나를 하나` — 1막은 사물 호칭(`저거`)이어야 하는데 1인칭 분화가 먼저 나온다 |
| 204, 212, 228 | 2막 | `하나는`(사물화 후퇴) / `쟤`와 `다른 나` 혼용 |
| 239, 247, 255, 261 | 3막 | 망설임 없는 순수 `쟤`(2막 호칭) / `저쪽 나`(2막 예시 어휘) |

## 7. 판단 보류 — 팀 확인 후 결정

- **hud.ts:1836** `다시 녹화할 잔상을 고르시오` — 시설 인쇄체(stencilBig)로 그리는데
  내용은 플레이어를 향한 명령조. 시설 톤을 살리면 `잔상 덮어쓰기 — 대상 선택`,
  UI 톤이면 `다시 녹화할 잔상 선택`. **추천: 시설 톤** — 이 화면 자체가 "시설이
  회수 대상을 고르게 한다"는 서사와 맞물린다.
- **hud.ts:2902** YIELD 엔딩 body `당신은 나갔다.` — STORY.md 정본은 `당신은
  나간다`(현재형)이고, 다른 두 엔딩 body는 무주어 3인칭이라 이 엔딩만 2인칭이 나온다.
  단 "이 결말이 가장 아프도록"이라는 정본 의도상 2인칭 호명이 의도일 수 있다.
  **추천: 유지**, 시제만 정본과 통일할지 팀 확인.
- **hud.ts:1270** `한 번 더!` — 느낌표가 붙은 유일한 라벨이고, SKIP 확인 맥락에서
  의미가 반대로 읽힐 소지.
- **`녹화` 용어 정책** (hud.ts 644·1839·3128 등) — 카메라 은유라 세계 밖 어휘지만
  여러 화면에서 내부적으로 일관되게 쓰이고 있어 단독 교체는 부적절. 바꾸려면
  `다시 남기기` 계열로 전 지점 일괄 교체해야 한다.
- COMIC-SCRIPT 제3부 END-3 [연출]의 `회수 양호.` → `전 배치 잔여물 — 수거 완료.`(채택분)
  두 줄 연출: hud.ts에는 현재 한 줄뿐이다. 두 번째 줄을 추가하는 건 워딩 교체가 아니라
  연출 추가이므로 이 지시서 범위에서 뺐다 — 팀이 원하면 별도 작업으로.
