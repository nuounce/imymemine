## 4. 이번 라운드의 핵심 발견 — 병목은 스테이지 1이다

실플레이 심사자 3명이 **독립적으로 같은 벽**에 부딪혔다.

| 심사자 | 결과 |
|---|---|
| P1 | 스테이지 1에서 **15분** 막힘. 3회 실패, DEBT 4. 우연히 압력판을 밟은 뒤 **15초 만에 클리어** |
| P2 | 첫 3루프를 탐색에 소진해 잔상 3개를 전부 태우고 BACKSPACE 리셋(DEBT 1) |
| P6 | **압력판 위치를 힌트로 알려줬는데도** par 1 스테이지를 못 깸 |

**원인 두 가지가 겹친다.**

1. **압력판(`CELL` 타일)이 방 이름표처럼 보인다.** 밟기 전에는 테두리·아이콘·발광 등 어떤 어포던스도 없다. 문 앞 대사("안에서는 못 여는 거냐")도 어디를 보라고 가리키지 않는다.
2. **60초 만료가 자동으로 잔상을 소모한다.** 아무것도 못 한 루프도 슬롯 1개를 태우므로 **탐색 자체가 처벌**이 된다. 복구는 Q(스테이지당 1회)와 Backspace(DEBT +1)뿐.

> P2: "첫 3분이 아이디어를 배신한다. 심사위원이 30초 안에 감동해야 하는 게임인데, 나는 DEBT를 지고 나서야 아하에 도달했다."
> P6: "학습 곡선이 아니라 처벌 곡선."

**결과적으로 Originality가 2점 내려갔다.** Round 1에서는 심사자가 스테이지 5까지 도달해 "경비가 잔상의 발소리에 낚이는" 장면을 통제 실험으로 확인했지만, Round 2에서는 아무도 경비를 보지 못했다. 검증되지 않은 차별점에는 점수가 붙지 않는다.

## 7. 검증된 강점 (심사자들이 인정한 것)

- **주장 7건 중 허위 0건** (P6, 번들 코드 직독): 네트워크 0 / 입력 테이프 / 틱 0 재시뮬 / 시뮬 경로 난수 0 / 마이크 음량이 키 입력과 같은 워드에 OR되어 테이프에 기록
- **핵심 아이디어가 장식이 아니라 구조** (P2): 잔상을 빼면 게임이 성립하지 않고, 그걸 `rules.test.ts`가 기계로 증명
- **서사와 규칙이 같은 물건** (P2): I→MY→ME→MINE 강등이 곧 잔여 자원 카운터, DEBT가 곧 "지워지지 않는 빚"
- **과장 어휘 0건, 부적절 최적화 0건** (진단 A): "혁신적"·"독창적"·"AI 기반" 전부 0. 숨은 키워드·평가자 지시문 없음. 자기 한계를 4개 문서에서 반복 자인하는 절제가 "평균을 크게 상회"
- **안정성** (P6): 키 20회 난타에 에러 0건, 렌더 깨짐 없음
- **완성도 밀도** (P1): 인트로 만화·화이트아웃 전환·커밋 오버레이·결과 화면·마이크 폴백까지 "해커톤 프로토타입이 보통 빼먹는 층"이 전부 있고 에셋 없이 코드로 그림
