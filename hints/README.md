# 힌트 문서 안내

이 디렉터리는 게임 안에서 플레이어에게 나가는 힌트 문구를 버전별로 다듬어 가는 곳입니다. 이 파일에는 버전이 바뀌어도 변하지 않는 정보만 둡니다. 실제 문구는 `v1.md`, `v2.md` 처럼 번호를 붙인 파일에 담습니다.

## 파일 규칙

| 파일 | 역할 |
| --- | --- |
| `README.md` | 힌트 체계 설명과 용어 정리. 지금 이 문서입니다. |
| `v1.md` | 조사 시점(2026-08-26, 커밋 `0712673`)의 코드에 들어 있던 문구 원문. 기준선입니다. |
| `v2.md` 이후 | 피드백을 반영해 다듬은 문구. 이전 버전은 지우지 않고 남깁니다. |

버전 파일에는 문구만 담습니다. 개선 이유나 논의는 커밋 메시지에 남기세요.

## 힌트 체계는 두 갈래다

같은 스테이지에 성격이 다른 두 종류의 힌트가 붙어 있습니다. 문구를 고칠 때는 둘이 서로 어떤 관계인지 보고 판단해야 합니다.

### 1. 정답 한 줄 (수동, T키)

플레이어가 직접 열어야 나오는 최후 수단입니다. 스스로 풀 기회를 다 쓴 사람에게 주는 것이라 해법을 바로 말합니다.

| 항목 | 내용 |
| --- | --- |
| 원문 위치 | `src/game/levels.ts` 각 스테이지의 `hint:` 필드 |
| 해금 조건 | 그 스테이지에서 5회 실패해야 열립니다 (`HINT_UNLOCK_FAILS = 5`, `src/sim/constants.ts:343`) |
| 조작 | `T` 키를 누르거나 화면 우하단의 `T ▸ HINT` 칩을 누릅니다 (`src/engine/input.ts:81`, `src/main.ts:683`) |
| 그리기 | `src/render/hud.ts:1294` 의 `drawHintBanner`. 하단 밴드 바로 위 중앙에 뜹니다 |
| 분량 | 스테이지당 한 줄 |

### 2. 주인공 속말 (자동, 단계별)

플레이어가 부르지 않아도 알아서 나옵니다. 주인공이 흘리는 혼잣말 형식이라, 설명하는 말투가 아니라 생각하는 말투여야 합니다.

| 항목 | 내용 |
| --- | --- |
| 원문 위치 | `src/game/whisper.ts` 의 `STAGE_WHISPERS` (150행 부근) |
| 구성 | 스테이지마다 `opening` 한 줄과 `steps` 여러 줄 |
| `opening` | 스테이지에 들어서면 즉시 한 번 나옵니다 |
| `steps` | 진전이 없는 채로 720프레임(약 12초)이 지나고 그때 서 있는 타일이 이미 가본 곳이면, `hintLevel` 이 1 올라가면서 다음 단계가 나옵니다 (`src/game/whisper.ts:593`) |
| 중복 | 같은 대사는 한 스테이지에서 한 번만 나옵니다 |
| 구체화 | 뒤로 갈수록만 구체적이어야 합니다. 첫 단계가 정답이면 퍼즐이 죽습니다 |

`steps` 는 진전 서명이 바뀌면 정체 카운터가 풀리므로, 플레이어가 뭔가를 해내는 동안에는 다음 단계로 넘어가지 않습니다.

### 힌트가 아닌 대사

`src/game/whisper.ts` 에는 힌트가 아닌 대사도 함께 들어 있습니다. 이 디렉터리의 작업 범위 밖입니다.

- `GLOBAL_LINES`: 스테이지와 무관하게 상황이 만들어 내는 속말입니다. 게이트에 부딪히거나 섬광탄을 줍는 것처럼요.
- `ACT_LINES`: 막이 올라갈수록 잔상을 부르는 호칭이 바뀌는 연출용 대사입니다.

## 용어

**par**: 메달 기준이 되는 잔상 수입니다 (`src/sim/types.ts:358`). 사용한 잔상이 par 이하면 `MINIMUM AFTERIMAGE ★` 를 받습니다. 그 스테이지를 가장 적은 잔상으로 푸는 방법이 몇 개를 쓰는지 나타내므로, 힌트가 얼마나 구체적이어야 하는지 가늠하는 척도가 됩니다.

**잔상**: 플레이어가 `R` 로 남기는 과거의 자기 자신입니다. 남긴 시점까지의 조작을 그대로 다시 재생합니다. 한 스테이지에서 최대 3개까지 쓸 수 있어요 (`MAX_AFTERIMAGES = 3`, `src/sim/constants.ts:37`).

**막**: 스테이지를 넷으로 묶은 단위입니다. 레벨 id 의 두 번째 토큰이 곧 막을 가리킵니다. `01_I` 는 1막, `15_MINE_FINAL` 은 4막이에요 (`SLOT_NAMES = ['I', 'MY', 'ME', 'MINE']`).

| 막 | 이름 | 스테이지 | 새로 나오는 장치 |
| --- | --- | --- | --- |
| 1 | 수용 | 01~04 | 없음. 발판, 게이트, 상자로만 굴립니다 |
| 2 | 감시 | 05~08 | 경비, CCTV, 레버, grate(소음 바닥) |
| 3 | 통제 | 09~12 | seqButton(순차 버튼), laser(주기 레이저), flash(섬광탄) |
| 4 | 경계 | 13~15 | powerBus(전력 채널). 하나를 켜면 하나가 꺼집니다 |

**오프닝**: 속말의 `opening` 입니다. 스테이지 진입 직후 한 번 나옵니다.

**막힘 단계**: 속말의 `steps` 입니다. 정체가 쌓일 때마다 순서대로 하나씩 나옵니다.
